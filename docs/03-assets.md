# 素材规范与已知坑

> 面板的"长相"几乎全在素材里（底图 + 拨杆贴图）。这一节记录**已验证过的做法**与**踩过的坑**，
> 都来自 legacy Sparklin Drive（`sparklin-drive-legacy`）的实机验证。

---

## 1. 两种素材

| 素材 | 格式 | 谁画 | 运行时怎么用 |
|---|---|---|---|
| 面板底图 | PNG（通常是 `@2x`） | 设计器导出 | 整张铺在 `rect` 上（等比缩放到素材坐标） |
| 拨杆两态 | PNG（通常 `@4x`，需要 alpha） | 设计器导出 | 按 `[ui.toggle]` 的 `x/y/w/h` 贴上去 |

> 指针、LED 亮灭、按下缩放**都由运行时画**，不要画进底图（否则会重影）。

---

## 2. 像素密度（@2x / @4x）

- 底图：按 `window_width × window_height` 的 **2 倍**出图（Retina 清晰）。
  legacy 用 `340×635` 窗口 → `680×1270` 的 PNG。
- 拨杆贴图：legacy 用 `@4x`（`23.68×25.21` 素材单位 → 约 95×101 px）。
- 运行时会按 `rect 尺寸 × pixels_per_point` 重新采样，**素材分辨率只决定清晰度上限**，
  不决定布局。

---

## 3. 三个已经踩过的坑

### 3.1 PNG 的 alpha 被忽略 → 拨杆"发糙"

早期导出时把「背景透明」当成了「不要背景」，结果 alpha 通道丢失、边缘变成硬锯齿或黑边。
**导出拨杆贴图时必须保留 alpha**，并且：
- 面板底图上对应位置要留空（或画成凹陷的底色），
- 不要给拨杆贴图加投影（运行时缩放时会跟着放大）。

### 3.2 两态贴图的基线不一致 → 切换时"跳一下"

legacy 的两张拨杆贴图，六边形水平两顶点连线在中轴上的位置差 **1.53（素材坐标）**。
用同一个 `y` 会导致切换瞬间整体位移。
→ 这就是 `[ui.toggle]` 有 `y_up` / `y_down` 两个字段的原因。
**设计器必须分别记录两态的基线**（或在导出时自动对齐并写对两个 y）。

### 3.3 指针画在底图上 → 拖动时重影

指针由运行时按参数值绘制。如果底图里已经画了指针，就会看到"两根针"。
→ 底图只画**旋钮本体**（刻度、凹槽、丝印），指针位置留空。

---

## 4. 素材坐标 ↔ 像素

设计器内部建议：**以素材坐标（`svg_width × svg_height`）为唯一编辑坐标**，
导出时按固定倍率（2×/4×）栅格化。这样：

- 控件坐标直接就是 `[ui]` 里的数字，不需要换算；
- 换显示器/HiDPI 不需要改布局；
- 与底图 SVG（如果有）共用同一套 viewBox。

---

## 5. 目录约定

```text
<插件项目>/assets/
├── panel@2x.png
├── switch_up@4x.png
└── switch_down@4x.png
```

文件名里的 `@2x/@4x` 是**说明性**的（运行时只看 `[assets]` 里的路径），
但保留这个习惯能让"哪个素材是几倍"一眼可见。

## 6. 分辨率：legacy 面板实测（2026-10-26 实测数据）

这一节回答"导出该用多少 PPI"，数据直接量自 `sparklin-drive-legacy` 的素材。

### 6.1 legacy 的实际数字

| 项 | 值 |
|---|---|
| SVG 画布 | `viewBox="0 0 170.08 317.48"`，单位是 **pt**（1 unit = 1/72″） |
| 物理尺寸 | 170.08 pt = **60.0 mm** 宽 · 317.48 pt = **112.0 mm** 高（= 1590B 竖放） |
| 窗口逻辑尺寸 | `340 × 635 px` → **5.667 px/mm ≈ 144 dpi** |
| `panel@2x.png` | `680 × 1269 px` → **≈ 288 dpi（11.33 px/mm）** |
| `switch_up/down@4x.png` | `95 × 101 px`，材质 `23.68 × 25.21 pt` = 8.35 × 8.89 mm → **≈ 289 dpi** ✓ 一致 |
| `source/panel_source.png` | `2835 × 5292 px @1200 dpi` = **60.0 × 112.0 mm** ✓ 完全吻合 |

**换算链**：`1 pt = 0.3528 mm`；窗口里 `1 pt = 2 px`；导出时 `1 pt = 4 px`（= 2× Retina）。
所以导出密度 = **4 px/pt = 11.33 px/mm ≈ 288 dpi**。

### 6.2 ⚠️ PNG 元数据里的 DPI 是假的

```
panel@2x.png             dpi = 384
switch_up@4x.png         dpi = 385
source/panel_source.png  dpi = 1200   ← 只有这个是真的
```

按 384 dpi 算，680 px 只有 **45 mm** 宽 —— 与实际 60 mm 对不上。
判断素材清不清晰**只能看「像素数 ÷ 物理尺寸」**，不要读 PNG 的 DPI 字段
（那是导出工具的副作用，被反复缩放/裁剪后就不成立了）。

### 6.3 为什么 legacy"窗口一大就糊"

运行时每次按 `rect 尺寸 × pixels_per_point` 重建纹理：

```rust
let want = [rect.width() * ppp, rect.height() * ppp];
```

2× 显示器 + 340×635 窗口要 680×1270 px，而素材正好是 680×1269 → **刚好 1:1，没有余量**。
用户把窗口拉大就必然上采样。

### 6.4 本项目的导出密度约定

| 项 | 取值 | 说明 |
|---|---|---|
| **逻辑窗口** | `mm × 6 px/mm`（152.4 dpi） | 60 × 112 mm → **360 × 672** |
| **导出素材** | `mm × 12 px/mm`（304.8 dpi） | 60 × 112 mm → **720 × 1344** |
| 公式 | `px = mm × 12`，`window_px = mm × 6` | 一行乘法，无小数密度 |

选择理由：

1. 12 是整数 → 导出代码不会出现 11.33 这种密度；
2. 比 legacy 高约 6%，2× 显示器下有余量；
3. 与 `gb4728-symbols-kit` 的「1 单位 = 1 mm」一致，符号/旋钮素材可 mm 直接摆放。

> 可选：底图再留 1.5× 余量（18 px/mm）应对"用户把窗口拉大"。成本是内存
> （720×1344 ≈ 0.95 MB → 1080×2016 ≈ 2.2 MB）。第一版取 12 px/mm，
> 高分辨率导出作为后续选项。

## 6. 现有素材清单（2026-10-26，自动索引）

素材全部按 **pt 坐标 + viewBox** 画（Illustrator/Inkscape 默认），尺寸由
`scripts/gen-assets.mjs` 从 viewBox 读出来写进 `src/assets.gen.js`（入库、可 diff、`--check` 防漂移）。

| 目录 | 内容 | 尺寸（mm） |
|---|---|---|
| `knobs/` | `knob_round_dark`（15.0 / 用这个）、`knob_round_light`（20.35）、`knob_heptagon_large_dark`（27.0） | 指针朝上，运行时整图旋转 |
| `sw/` | `toggle_small_{up,down}`（8.35×8.89）、`toggle_large_{up,down}`（14.35×15.30）、`3pdt_alt`（14.35）+ **`3pdt_alt_hold`（按住态，同尺寸）** | 拨杆两态各自一张；脚踏有按住态就整张换 |
| `leds/` | `led_{red,green,blue}` | 6.27；外圈 r=3.0，**镜片 r=2.249**（运行时画这个半径） |
| `labels/` | 23 个单词丝印（attack/bias/boost/clip/comp/depth/dist/drive/fuzz/gain/input/level/mix/output/range/rate/release/sustain/tone/volume…） | 高 2.37，宽随字；**全部是矢量 path，不是文字** |

> 标签是 path 的这点很重要：运行时不渲染任何文字，所以不受宿主字体影响。
> 也因此设计器**不需要**字体渲染（D-003「文字一律栅格化」）。

## 7. 内联素材时的三个坑（都已在代码里解决，见 D-006）

| 坑 | 现象 | 解法 |
|---|---|---|
| path 坐标远在 viewBox 之外（`M253,393`） | 用 `<g transform>` 贴上去，图形跑到面板外面 | 用**嵌套 `<svg x y width height viewBox>`**，由嵌套 viewport 裁剪 |
| 每个素材都叫 `.cls-1` / `.cls-2` | 内联多份时后一个把前一个的颜色覆盖掉 | 把 `<style>` 规则**展开成内联 `style`**，删掉 `<defs><style>` |
| 自闭合标签（`<circle/>`）的样式加在 `/` 之后 | 样式被丢弃 → 圆变成黑色实心块 | 先剥掉尾部的 `/`，加完属性再补回去（`tests/embed.test.mjs` 有回归） |
| `id="layer1"` / `id="svg1"` 重名 | 引用错乱 | 内联时删掉所有 `id` / `data-name` |

## 8. 按住态（hold）约定

`<id>_hold.svg` 会被自动识别为 `<id>` 的按下态（`scripts/gen-assets.mjs` 配对）：

- **画布尺寸必须与常态一致**（不一致会在生成清单时告警，按住时会跳）；
- 因为它整张替换，所以"按下"的效果要画在素材里（内圈缩小/阴影等），而不是靠缩放；
- 导出时它会作为独立 PNG 出现在 `[assets]` 里，`[[ui.buttons]]` 带 `image_hold` + `image_size`。

> 命名里的 `-` 会被规范成 `_`（`3pdt_alt-hold.svg` → `3pdt_alt_hold`）。
