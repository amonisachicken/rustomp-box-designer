## 归档流程

1. **判断**：这段内容是否已经不能代表"现在"？（方案定稿、交互改了、功能删了）
2. **落盘**：新建/追加 `history/<主题>.md`，顶部写归档日期、原因、替代文档；
   保留原始结论，不改写历史。
3. **留指针**：在当前文档原位置留一行"历史见 …"，或直接删除并在本索引登记。
4. **登记**：更新本页索引（内容 / 原因 / 替代）。
5. **查链接**：移动文件后修正相对链接，并跑一次链接检查。

> 新增开发内容时：**先更新当前文档/`status.md`**；被替换下来的旧描述才进这里。
