## 2. 已知限制（当前）

- **交互**：拖动是刻意关掉的（D-012）；定位只走方向键 / 数值输入 / 对齐按钮。
  没有框选（多选已可用）、没有素材热重载。
- **显示**：没有数值显示 / 表头指针（D0 明确不做，等有真实需求）。
- **打印**：没有 1:1 打印 PDF；`panel.svg` 可作为矢量源。
- **PNG**：浏览器 zip 里的 PNG 与 Inkscape CLI 的 PNG **像素尺寸一致、字节不同**（抗锯齿不同）；
  CI 以 CLI 那份为准。
- **工程格式**：只支持 `.box.json` `version: 1`，没有版本迁移链；旧字段靠 `load()` 补齐。
- **暂存**：只有"上一次一份"，没有多草稿列表/冲突合并；静态托管（无开发服务）时不可用。
- **边界**：不碰 DSP、电路、参数表、插件身份（名字 / AU 码 / VST3 id）。
